# 코나미 폭발 효과음

직접 합성한 게임용 WAV 초안. 실제 폭발 녹음이 아니다. 모두 44.1 kHz, 16-bit, mono.

- code_success.wav: 0.32초, 입력 성공 기계음
- explosion_small.wav: 0.40초, 연쇄 폭발용 짧은 충격
- explosion_big.wav: 1.10초, 메인 폭발의 저음과 충격
- explosion_tail.wav: 1.00초, 잦아드는 잔향과 잔불

작은 폭발을 연달아 재생할 때는 볼륨을 낮추고 피치를 조금씩 바꾼다. 메인 폭발과 잔향이 겹치는 구간의 총음량을 조정하고 기존 타이틀 효과음/음소거 설정을 적용한다. 파일 형식과 피크는 확인했으며, 실제 게임 사운드와 함께 청감 조정이 필요하다.

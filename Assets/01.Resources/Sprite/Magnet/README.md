# 자석 이스터에그 리소스

`자석`을 입력하면 전자석이 내려와 고철과 타이틀 버튼을 끌어당기는 연출용 이미지.

- magnet_body.png: 청록 도장과 경고 줄무늬가 있는 전자석 본체
- magnet_chain.png: 본체 위에 연결하는 체인
- magnet_field.png: 본체 아래에서 위로 끌려가는 자력 파동
- magnet_detach_spark.png: 버튼이 뜯기거나 다시 붙을 때의 짧은 불꽃

내장 image_gen으로 생성한 개별 투명 PNG. 프레임 애니메이션 시트가 아니므로 위치·회전·크기·알파를 코드로 움직여 사용한다. 고해상도 도트풍 이미지이며 고정 저해상도 픽셀 격자를 보장하지 않는다. 원본 알파를 유지했다.

Unity 임포트 시작값: Sprite (2D and UI), Single, Pivot Center, Point 필터, Mipmap Off, Compression None. 실제 표시 크기에서 픽셀 밀도를 맞춘다. 이미지의 투명 여백을 고려해 피벗과 표시 영역을 조정한다.

## 배치

체인은 본체 뒤에서 상단 고리에 이어지게 배치한다. 체인은 완전한 무봉제 타일이 아니므로 여러 조각을 이어 쓸 때 끝 링크를 겹쳐 맞춘다. 자력 파동은 본체 아래에 두고 위로 이동하면서 작아지고 사라지도록 반복한다. 실제 고철 부착 위치는 본체 하단의 금속 면이다.

## 버튼 처리

별도의 버튼 이미지는 제작하지 않았다. 실제 타이틀 버튼의 배경과 글자를 복제하고 클릭 이벤트·레이캐스트를 끈 연출용 오브젝트를 사용한다. 원본 버튼 위치와 활성 상태를 보관하고, 클릭/Esc/자동 종료 및 씬 전환 시 복구한다. 원본 버튼을 수정하는 작업은 포함하지 않았다.

## 연출 제안

1. 자석과 체인이 내려오며 magnet_on 재생.
2. magnet_hum_loop를 낮게 반복하면서 고철부터 끌어당김.
3. 버튼이 흔들리다 차례로 뜯길 때 분리 불꽃과 button_detach 재생.
4. 마우스 이동에 따라 자석과 매달린 물체가 흔들림.
5. 해제 시 magnet_off를 재생하며 지속음을 짧게 페이드아웃.
6. 고철은 낙하하고 버튼 복제본은 원래 자리로 돌아가며 button_return 재생.
